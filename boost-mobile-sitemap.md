## Key Commerce Flows

### 1. Buy a New Phone + Plan
`Home` → `Shop Phones` → `Select Device` → `Choose Plan` → `Configure Line (new # or port-in)` → `Cart` → `Checkout` → `Activation`

### 2. Bring Your Own Device (BYOD)
`/plans/byod` → `Check IMEI compatibility` → `Choose Plan` → `Keep Number or New Number` → `Order SIM` → `Checkout` → `Activate SIM`

### 3. Switch / Port-In
Any buy flow → `Keep My Number` → `Enter carrier info + port-in PIN` → `Checkout` → `Activation`

### 4. Add a Line (Multi-line)
`/plans/multiline` → `Configure lines` → `Add to cart` → `Checkout` (multi-line discounts applied automatically)

### 5. Upgrade (Infinite Access)
`Boost App / Account` → `Request upgrade after 12 payments` → `New device shipped` → `Trade in old device`

### 6. Activation (New Device or SIM)
`/activate` → `Enter IMEI / SIM number` → `New Number or Port-In` → `Create Account & Payment` → `Confirm Activation` → `Service Live`

### 7. Add-On Purchase
`/add-ons` → `Select add-on` → `Add to account` → `Confirmation`
